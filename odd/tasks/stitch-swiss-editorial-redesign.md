# Rediseño completo con Stitch — Swiss Editorial Developer Portfolio

## Objetivo
Reemplazar el diseño cinemático actual (branch `feat/editorial-redesign`: scrollytelling, pin horizontal, spotlight stack) por el diseño generado en Stitch — proyecto `Swiss Editorial Developer Portfolio` (`projects/14021720590587673727`), sistema de diseño "International Typographic Modernism".

## Por qué
Camilo quiere diferenciarse de portafolios "genéricos con IA" (gradiente morado, glassmorphism, iconos 3D) con algo más limpio, formal y editorial, pero que siga sorprendiendo con animación con propósito. Decisión explícita: rediseño completo desde cero, descartando el trabajo cinemático previo (no se borra del repo, simplemente se deja de construir sobre él).

## Fuente de verdad
- Contenido: `PERFIL.md` (raíz del repo).
- Diseño: proyecto Stitch `projects/14021720590587673727`, variantes **"Interactive Studio Edition"** elegidas para Perfil, Stack Técnico, Experiencia, Proyectos y Certificaciones; única versión para Contacto. Variante rota descartada: "Perfil — Camilo Henriquez (Interactive)" (screen `1f32c1e6b17c4284a90311b584412308`).

## Sistema de diseño (tokens, de Stitch)
- Dark mode. Fuentes: Space Grotesk (headlines), Hanken Grotesk (body), JetBrains Mono (metadata/labels/índices).
- Paleta: canvas `#0D0D11` / `#131318` / `#18181F`, texto `#F4F4F6` / `#A1A1AA` / `#63636E`, hairlines `#24242D` / `#1C1C24`, acentos `#E63926` (vermilion, uso parsimonioso) y `#2D68FF` (cobalt, para MCP/certificaciones).
- Roundness: 0 (esquinas 100% cuadradas). Sin sombras — profundidad por contraste tonal de superficie + hairlines de 1px.
- Grid: 12 columnas asimétrico desktop (máx 1440px), 8 columnas tablet, 4 columnas mobile.
